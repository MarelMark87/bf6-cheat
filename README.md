## 🎮 О проекте

Концепт компактной панели для визуального оформления проекта BF6: лаконичные вкладки, контролы и тёмная тема.

## ✨ Визуальные разделы

| Раздел | Элементы интерфейса |
| --- | --- |
| **Player** | Player ESP, Box ESP |
| **Aim** | Aimbot, FOV |
| **Settings** | Переключатели, назначение клавиш |
